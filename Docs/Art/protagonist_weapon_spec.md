# 主角武器规范：污光断剑 · 残誓

`protagonist_sprite_spec.md` 管角色尺度与动作 sheet；本文管**近战主武器**的造型、叙事阶段、出图与 VFX 边界。

英文内部名：`stained_oathblade`  
中文正式名：**污光断剑 · 残誓**（简称「残誓」）

---

## 1. 锁定结论

| 项 | 值 |
|----|-----|
| 类型 | 仪式臂剑偏短一档（非匕首、非双手巨剑、非权杖、非双持） |
| 用途 | 一期唯一主武器；普攻 / 冲刺刺痕 / 下砸落地冲击共用此形 |
| 色板 | 黯铁 · 苍金 · 琥珀裂纹光 · 可选极淡褪红污渍 |
| 母题 | 开裂圣徽护手 + 柄端四角星钉（与刺环同族）+ 刃缝污光 |
| 禁止 | 完整光环圣剑、主教权杖形、过长双手巨剑、抢刺环戏份的镰刃 |

**一句话：** 教堂仪式短剑被诅咒纵向裂开，刃缝渗琥珀色污光——朝圣者不肯交还的未完成之誓。

## 2. 外形细则

### 2.1 比例（相对 chibi）

以 idle 头宽为尺（约等于刺环内径量级，目测即可）：

| 部位 | 比例 | 说明 |
|------|------|------|
| 刃长（护手→刃尖） | **1.1～1.25 头宽** | 相对加长稿约再缩 **20%**；挥砍仍可读，垂持刃尖约在膝下、勿拖地 |
| 柄长 | **约 0.35～0.45 头宽** | 单手握持；下砸可双手 |
| 护手宽 | **约 0.4～0.45 头宽** | 小十字 / 开裂圣徽，勿做成大圆盘护手 |
| 刃宽（最宽处） | **约 0.13～0.18 头宽** | 偏薄仪式剑；侧视可辨即可 |

整剑从柄端到刃尖：**约 1.45～1.65 头宽**。  
仍禁止接近全身高的巨剑。idle/run 垂持或斜挂时刃尖不要穿进地面像素；空中帧同样脚踩底线、刃可出画框。

### 2.2 部件

| 部件 | 造型 |
|------|------|
| **刃** | 黯铁灰直刃；中段有一道纵向裂纹；刃尖略残，勿画成完美新铸 |
| **污光** | 裂纹与刃缘在攻击/能力帧渗 **琥珀色**（对齐角色瞳色）；静止可极暗或仅细线 |
| **护手** | 小十字或开裂圣徽，呼应胸甲十字，但更碎、更尖角 |
| **柄** | 黑革缠绕 + 苍金环；握感偏旧 |
| **柄端** | 一枚 **四角星钉**（与头上刺环星饰同族，略小） |
| **鞘** | 可选：黯皮斜鞘，口沿苍金；idle/run 可只露鞘或半露柄 |

### 2.3 与角色外观的关系

- 金属苍金、黯铁与胸甲 / 护臂一致；勿另起一套高饱和色。
- 琥珀光只出现在**刃缝 / 刃缘 / 刀光 VFX**，不要整把剑变金黄光柱。
- 碎翼披风、刺环仍是身份锚点；攻击帧里**刃可以更抢眼**（加长就是为了挥砍可读），但装饰复杂度仍勿超过刺环。

## 3. 叙事阶段（外观渐进，可选）

与 `Docs/Script.md` 内心弧光对齐。一期可只做「基础持刃 + 污光亮起」两态；终局态可后补换皮。

| 阶段 | 何时 | 外观 / 玩法 |
|------|------|-------------|
| **空手** | 教堂 getup ～ 取得残誓前 | **无刃、无普攻**；仅走/跳。剪影为人+披风；鞘可未挂或空鞘（实现不必另出整套 sheet） |
| **抗拒** | 教堂底层取得残誓 ～ 取得污光前 | 持刃；裂纹暗淡如锈蚀；几乎无琥珀光。解锁近战 |
| **承认** | 取得「污光 Stained Light」后 | 挥击时裂纹亮起；刀光为浑浊琥珀 |
| **驾驭** | 钟楼 / 时间能力后（可选） | 刃缝如微型灯芯；收招可残影像被抹去的朝圣剪影 |

**取得残誓（序章）：** 教堂底层、冲刺教学前。墙龛**没收架**交互夺回（不洁证物）→ 短演出斜挂/握持 → 解锁 Attack。出生点旁与拾剑后出口前各一座存档。下一间立刻小战斗或靶子。房间规格：[Rooms/cathedral_intro.md](../Rooms/cathedral_intro.md)。

### 3.1 来历（锁定 · 表层）

本为教堂发放的祈福仪式短剑：抵达祭坛后应交还圣域。朝圣者曾许誓护妹至净化完成。净化杀死妹妹之日刃纵向开裂；教堂登记为不洁证物并没收上架，朝圣者拒认「该被洗净」。序章夺回的是**未交还的誓**，不是承认诅咒——污光才点亮刃缝。

叙事锚：本为祈福仪式剑；净化杀死妹妹后裂纹成为诅咒证物，拒绝交还圣域。拿回残誓 ≠ 承认诅咒；污光才点亮刃缝。

## 4. 各动作如何画武器

目录仍为：`Assets/Art/Characters/Animations/{action}/`（单帧 PNG）  
角色尺度、绿幕抠图、PPU、脚底 pivot 一律遵循 **[protagonist_sprite_spec.md](./protagonist_sprite_spec.md)**。

| 动作 | 武器呈现 | 要点 |
|------|----------|------|
| **idle / run / jump / getup** | **可不拔刃**：斜挂左胯鞘，或碎翼内侧只露柄端星钉 | 避免每帧重画整刃；剪影仍以人+披风为主 |
| **attack** | **必须完整露刃** | 3～5 帧：见下节 |
| **hurt** | 可松握或刃下垂 | 勿突然消失 |
| **death** | 刃落地或裂纹光熄灭 | 1 帧示意即可 |
| **冲刺（能力）** | 刃尖朝前；可另出残影 VFX | 角色帧仍是短剑形 |
| **下砸（能力）** | 双手握柄 Overhead → 砸地 | 着地冲击环走 VFX，勿画进角色脚底像素里「垫高」 |

### 4.1 Attack 帧（`Animations/attack/attack_N.png`）

建议 4 帧（可 3～5）：

| 帧 | 姿态 | 刃 |
|----|------|-----|
| `attack_0` | 起手蓄力（略后收） | 刃在身后或肩后，裂纹可微亮 |
| `attack_1` | 主挥中段（命中帧） | 刃在身前弧线最大；**此帧 hitbox 对齐** |
| `attack_2` | 收势或短刺 | 可选刺击，刃尖朝右前 |
| `attack_3` | 回 idle 过渡 | 刃收回鞘侧或放下 |

- 统一面朝右；脚底共线；站立内容高锁 idle ±5%。
- **刀光 / 污光弧**：优先独立 VFX（见 §5）；角色帧可只画实体刃 + 刃缝亮线。
- 刃长按 §2.1（约 1.1～1.25 头宽）；挥砍靠刃长 + VFX，不要画成全身巨剑。

### 4.2 持握手

- 普攻：惯用手（建议**右手**，面朝右时靠镜头或略前）。
- 下砸：双手。
- 与现有护臂造型一致，勿另造裸手。

## 5. VFX 边界

独立表或帧（可进 `asset_checklist` P2 VFX），**不要**为了刀光重绘整套角色：

| VFX | 用途 | 色 |
|-----|------|-----|
| `vfx_oathblade_slash` | 普攻弧光 | 琥珀半透明 + 薄黑铁描边 |
| `vfx_oathblade_thrust_trail` | 冲刺刺痕残影 | 短直线琥珀残影 |
| `vfx_oathblade_slam_ring` | 下砸落地环 | 琥珀冲击环，1～3 帧 |

原则：角色帧 = 实体；发光拖尾 = VFX。污光能力光晕（探索用）与刀光可同色，但造型区分（光晕是身周，刀光是刃迹）。

持刃概念为 **承认期** 外观与尺度锁定稿（右手持刃、刃缝琥珀、护手圣徽、柄端星钉；刃长 §2.1 **1.1～1.25 头宽**）；不进关卡动画。出 attack 帧时锁此造型与比例。

Unity：角色帧仍 PPU **256**、Pivot **Bottom**、Sprite Mode **Single**；纯武器 icon 可另定 PPU，但进关卡的持刃帧必须跟角色同一套导入规则。

## 7. 玩法对齐（给程序 / 手感）

一期不必换武器，只换「裂纹亮度」与 VFX。序章用 `HasOathblade`（或等价 flag）锁 Attack，取得残誓前不响应普攻输入。

| 玩家动作 | 武器逻辑 |
|----------|----------|
| 近战攻击 | 有残誓时打开 `AttackHitbox` 对齐 `attack_1`（或主挥帧）；命中框略大于刃长 |
| 冲刺 | 位移中可短开刺向 hitbox；残影用 VFX |
| 下砸 | 落地瞬间圆形 / 扇形 hitbox + slam ring VFX |
| 污光 | 探索能力；战斗上可加强琥珀刀光，**不换武器模型** |

不要与敌人仪式短剑（碎誓侍僧等）外形撞车：敌人用更锈、更短、无四角星柄端、无琥珀裂纹。

## 8. 出图自检

- [ ] 刃长约 1.1～1.25 头宽（整剑约 1.45～1.65 头宽）；非全身巨剑、垂持不拖地
- [ ] 护手开裂圣徽 + 柄端四角星钉可读
- [ ] 色板：黯铁 / 苍金 / 琥珀裂纹（琥珀不过量）
- [ ] idle/run 等非攻击帧可不拔刃；attack 帧刃完整
- [ ] 刀光优先 VFX，未把大面积光团画进角色不透明像素
- [ ] 攻击站立/挥击帧内容高相对 idle ±5%；脚底共线；透明底
- [ ] 未做成权杖 / 镰刀 / 双持 / 完整圣光剑
