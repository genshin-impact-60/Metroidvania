# 水淹洞窟 · 敌人图鉴

地下湖与湿岩晶洞：深青、湿岩灰、氰晶微光、暗水。敌人偏「溺亡朝圣、晶脉活体、潮汐祭仪」。

立绘目录：`Assets/Art/Enemies/cavern/`

## 溺潮遗者

| 字段 | 内容 |
|------|------|
| ID | `drowned_remnant` |
| 名称 | 溺潮遗者 |
| 定位 | 普通近战 / 浅滩 |
| 立绘 | `Assets/Art/Enemies/cavern/enemy_cavern_drowned_remnant.png` |

**外观**  
溺亡朝圣尸：水浸青灰肤、湿发贴面、乳白氰光瞳。湿重破圣袍挂藻与滴水，护腕锈绿；肩生藤壶与细小氰光生物灯。手持珊瑚锈蚀断剑，立于浅水。

**习性**  
浅滩与出水石柱巡逻，可短暂潜入再扑岸。近距挥砍，出水瞬间有扑击。

**战斗提示**  
水中移速变慢时勿硬刚。观察水面涟漪预判出水；上岸后硬直可打。优先在干平台作战。

## 晶脉岩卫

| 字段 | 内容 |
|------|------|
| ID | `crystal_warden` |
| 名称 | 晶脉岩卫 |
| 定位 | 精英 / 重型近战 |
| 立绘 | `Assets/Art/Enemies/cavern/enemy_cavern_crystal_warden.png` |

**外观**  
湿岩魔像：暗岩身嵌锯齿氰晶，脊与冠晶簇生长；无面石面具中央一颗亮氰晶眼。一臂化为巨型晶刃。苔湿关节不断滴水。

**习性**  
镇守晶台、闸门与宽平台。重劈、横扫，晶刃触地可溅出短距晶刺。受暴击时晶体碎裂掉落，短暂破防。

**战斗提示**  
读大前摇躲劈砍；碎晶窗口全力输出。勿站在正前方吃溅刺。远程风筝有效。

## 幽光水母灵

| 字段 | 内容 |
|------|------|
| ID | `jelly_wisp` |
| 名称 | 幽光水母灵 |
| 定位 | 飞行 / 控场骚扰 |
| 立绘 | `Assets/Art/Enemies/cavern/enemy_cavern_jelly_wisp.png` |

**外观**  
半人水母：人形上身与半透明发光水母伞盖融合，曳长氰光触须作下身与发丝。平静面庞、亮氰瞳，蹼爪细臂。伞盖与触须脉动青光，悬浮于暗水之上。

**习性**  
在浮晶平台与吊链台之间漂浮，触须鞭打并落下减速「电光水雾」。可短暂潜入水面再弹起。

**战斗提示**  
优先清，防叠减速后被重型敌人接杀。触须有甩动前摇；伞盖亮脉冲时即将喷雾，侧移躲开。

## 潮晶巫女

| 字段 | 内容 |
|------|------|
| ID | `tide_matron` |
| 名称 | 潮晶巫女 |
| 定位 | 区域头目 |
| 立绘 | `Assets/Art/Enemies/cavern/enemy_cavern_tide_matron.png` |

**外观**  
高挑潮汐女祭：湿岩与活氰晶构成的身躯，长发如水藻带氰光脉络；冠为尖晶与古石齿轮残片。下半身化为盘绕水晶蛇尾，自湖面升起。深青灰溺祭服、锈金属晶嵌胸甲；手持铁晶三叉戟，冷艳威严。

**习性**  
盘踞地下湖中央神殿。戟刺、尾扫掀浪、召唤溺潮遗者与升起晶刺平台改变站位；低血量时湖面上涨，压缩安全区并加强幽光水母灵增援。

**战斗提示**  
跟浪预警走位，别掉进深水太久。晶刺平台既是障碍也可借位。第二阶段优先清飞行单位。击败后可获「水下呼吸/潜水」类能力或通往钟塔的水闸钥（待定）。
