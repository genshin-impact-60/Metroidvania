# 大教堂 · 敌人图鉴

灰金圣堂、落信仰与褪红仪仗。敌人气质对齐主角「诅咒朝圣者」：破败圣装、苍金瞳光、冷月光与灰石。

立绘目录：`Assets/Art/Enemies/cathedral/`

| 字段 | 内容 |
|------|------|
| ID | `broken_acolyte` |

| 定位 | 普通近战 |
| 立绘 | `Assets/Art/Enemies/cathedral/enemy_cathedral_broken_acolyte.png` |

**外观**  
破败修女装、短乱灰褐发、开裂薄金属光环残片；苍白肤色、空洞金瞳。灰白圣袍 + 褪红腰带，赤足沾圣堂灰烬。右手锈蚀仪式短剑，左手腕锁链拴着开裂祈祷书。

**习性**  
在中殿与回廊低层巡逻，发现朝圣者后短距追击。人数可成对出现，压迫感来自数量而非单体强度。

**战斗提示**  
近身劈砍为主，读招窗口短但伤害普通。拉开距离或绕后打断其举剑即可；注意同伴从侧廊包抄。

## 泣血执旗者

| 字段 | 内容 |
|------|------|
| ID | `banner_penitent` |
| 名称 | 泣血执旗者 |
| 定位 | 精英 / 中距压迫 |
| 立绘 | `Assets/Art/Enemies/cathedral/enemy_cathedral_banner_penitent.png` |

**外观**  
瘦高中性体态，尸白肤、乳白金瞳、长黑发半掩面纱。黯色仪仗甲与灰袍，胸甲嵌彩玻碎片泛淡金光；腰间垂铁十字架与锁链。尖刺铁杆挑着大幅褪红游行旗，旗面隐约有圣徽残痕。

**习性**  
守在垂旗大厅与楼梯口，用旗杆扫击控场，偶尔以旗面遮挡视线后突进。胸甲金光会随蓄力脉动。

**战斗提示**  
攻击距离长、横扫范围大，贴身风险高。等横扫收招再进场；可利用平台高度差绕到身后。蓄力时胸光变亮，优先打断。

## 石喉守卫

| 字段 | 内容 |
|------|------|
| ID | `gargoyle_sentinel` |
| 名称 | 石喉守卫 |
| 定位 | 飞行 / 高台伏击 |
| 立绘 | `Assets/Art/Enemies/cathedral/enemy_cathedral_gargoyle_sentinel.png` |

**外观**  
活体石像鬼：灰石身躯裂开苍金矿脉；蝠翼石质、边沿风化破损；角首空洞金瞳。颈上铁环垂十字架。爪足利，蹲踞崖檐时几乎与建筑融为一体。

**习性**  
静止时如雕像，玩家靠近或经过下方平台时俯冲扑击，也可短距滑翔换位。适合挂在高窗、柱顶、浮空平台边缘。

**战斗提示**  
抬头观察檐口金光裂痕可预判苏醒。俯冲有明显起跳前摇，侧移或下砸反制；落地硬直是主要输出窗口。空中战避免站在正下方。

## 伪圣主教

| 字段 | 内容 |
|------|------|
| ID | `false_bishop` |
| 名称 | 伪圣主教 |
| 定位 | 区域头目 |
| 立绘 | `Assets/Art/Enemies/cathedral/enemy_cathedral_false_bishop.png` |

**外观**  
枯老而威严的男性主教：尸白面、凹陷脸、无瞳苍金光眼、长白发分叉须。开裂金冠法冠、黑灰破祭服沾褪红污渍；身后漂浮破碎暗金尖刺光环。扭曲铁权杖顶端为倒立开裂十字架，渗淡金光。

**习性**  
盘踞大教堂最深处中殿祭坛。近战挥杖扫击，中距放出伪圣光柱 / 倒十字投射；低血量时召唤碎誓侍僧或唤起石喉守卫苏醒。姿态始终庄严，像在举行渎圣弥撒。

**战斗提示**  
第一阶段以读权杖轨迹与地面光柱为主；第二阶段注意增援清理优先级。光环碎片可作为危险区域提示。击败后可掉落区域关键钥匙或能力（待定）。
