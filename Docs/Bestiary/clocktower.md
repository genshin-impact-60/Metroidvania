# 机械钟塔 · 敌人图鉴

工业哥特垂直机厅：氧化黄铜、黯铁、铜锈、琥珀灯火。敌人偏「发条傀儡、蒸汽守关、时仪伪神」。五区收束关。

立绘目录：`Assets/Art/Enemies/clocktower/`

## 铆钉机兵

| 字段 | 内容 |
|------|------|
| ID | `rivet_automaton` |
| 名称 | 铆钉机兵 |
| 定位 | 普通近战 |
| 立绘 | `Assets/Art/Enemies/clocktower/enemy_clocktower_rivet_automaton.png` |

**外观**  
铆钉黯铁士兵：氧化黄铜覆甲，胸口暴露滴答齿轮泛琥珀光。无面盔仅一条琥珀灯眼缝，铜锈斑驳，肩冒蒸汽。手持短齿齿轮劈刀，立于金属格栅。

**习性**  
平台与梯子口巡逻，节奏固定如节拍器。近距劈砍，偶尔短距蒸汽冲刺。

**战斗提示**  
攻击有明显「上弦」停顿，卡拍闪避。蒸汽冲刺直线可预判。击破胸口齿轮有较长瘫痪。

## 摆锤铁卫

| 字段 | 内容 |
|------|------|
| ID | `pendulum_warden` |
| 名称 | 摆锤铁卫 |
| 定位 | 精英 / 重型控场 |
| 立绘 | `Assets/Art/Enemies/clocktower/enemy_clocktower_pendulum_warden.png` |

**外观**  
高大体蒸汽骑士：黯铁与氧化黄铜重甲，肩锅炉喷白汽，四肢铜管纵横。盔如裂钟面，琥珀光指针作眼纹。巨链悬齿轮摆锤刃，姿态压迫。

**习性**  
守在摆锤厅与宽跨距平台。甩锤弧扫、砸地震波，锅炉过热时扩大蒸汽区。可与场景摆锤同步威胁。

**战斗提示**  
弧扫范围大，贴身后背输出。砸地前跳起，落地后硬直。注意场景摆锤相位，借空档进场。

## 黄铜时翼

| 字段 | 内容 |
|------|------|
| ID | `chronowing` |
| 名称 | 黄铜时翼 |
| 定位 | 飞行 / 骚扰 |
| 立绘 | `Assets/Art/Enemies/clocktower/enemy_clocktower_chronowing.png` |

**外观**  
黄铜飞鸟机械：氧化黄铜与黯铁鸟虫合体，辐条齿轮翼曳琥珀光迹，铜锈花纹。尖喙首嵌单颗琥珀透镜眼，尾喷蒸汽与发条火花。悬停于浮空齿轮平台间。

**习性**  
俯冲啄击与短距琥珀光束扫射。可停在巨型齿轮边缘「上弦」后再加速。

**战斗提示**  
优先清，防平台战被干扰。俯冲直线好躲；上弦停顿是输出窗口。光束有蓄光预警。

## 时仪宗主

| 字段 | 内容 |
|------|------|
| ID | `chronarch` |
| 名称 | 时仪宗主 |
| 定位 | 区域头目（五区收束） |
| 立绘 | `Assets/Art/Enemies/clocktower/enemy_clocktower_chronarch.png` |

**外观**  
高耸发条神谕体：上身如机械大祭司，氧化黄铜与黯铁祭服式装甲；下身与巨齿轮王座、垂直发条脊骨融合。面为裂古董钟盘，琥珀数字与指针构成表情。脑后漂浮齿轮齿断金光环。手持顶端旋转黄铜时球杖，琥珀核心脉动。

**习性**  
盘踞钟塔顶机厅。杖击、时球放出「停顿力场」（玩家短暂减速）、召唤铆钉机兵与黄铜时翼；低血量时加速全场齿轮与摆锤，并释放大范围琥珀时爆。

**战斗提示**  
力场亮起时优先出圈或用无敌帧硬吃。清增援后再打本体。第二阶段跟场景机关节拍走位。击败后可获终局能力或通关钥匙（待定）。
