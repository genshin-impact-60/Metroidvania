# 蔓生废墟森林 · 敌人图鉴

被森林吞没的石砌遗迹：深绿、湿褐、苔青绿与苍白地衣。与大教堂灰金圣堂形成对比，敌人偏「自然夺回圣域」。

立绘目录：`Assets/Art/Enemies/forest/`

## 苔缚潜伏者

| 字段 | 内容 |
|------|------|
| ID | `mossbound_lurker` |
| 名称 | 苔缚潜伏者 |
| 定位 | 普通 / 伏击近战 |
| 立绘 | `Assets/Art/Enemies/forest/enemy_forest_mossbound_lurker.png` |

**外观**  
半人半苔：灰绿苍白皮肤覆地衣斑，空洞青绿瞳，发丝化作纠结根须。残存朝圣者灰布被活苔当甲；手臂缠藤，一侧延伸为带刺根鞭。蹲伏如从灌木下钻出。

**习性**  
藏于垂藤、苔台与中空树干/石管口，玩家靠近才现身。短距扑咬 + 鞭抽，可从平台下方或侧面偷袭。

**战斗提示**  
留意异常晃动的藤帘与青绿微光。现身有短暂破隐，先手打击；鞭抽有前摇，后跳或跳斩打断。勿在狭窄藤廊站死。

## 残碑守林人

| 字段 | 内容 |
|------|------|
| ID | `ruin_warden` |
| 名称 | 残碑守林人 |
| 定位 | 精英 / 重型近战 |
| 立绘 | `Assets/Art/Enemies/forest/enemy_forest_ruin_warden.png` |

**外观**  
活化石像骑士：灰石身覆厚翠苔与青绿地衣脉，肩生蕨叶与苍白苔花。石面半掩，眼窝燃闷青光。手持断石矛，矛身缠活根。体态厚重，立于废墟柱间。

**习性**  
镇守关键石门、祭坛残址与宽平台。移动慢，戳刺与横扫伤害高；受击过重时苔层剥落露出石核，短暂硬直。

**战斗提示**  
读矛尖轨迹，侧移进场打后摇。勿硬吃横扫。剥苔窗口是主要输出期；可利用高度差绕背。

## 孢翼幽蛾

| 字段 | 内容 |
|------|------|
| ID | `sporewing_moth` |
| 名称 | 孢翼幽蛾 |
| 定位 | 飞行 / 骚扰控场 |
| 立绘 | `Assets/Art/Enemies/forest/enemy_forest_sporewing_moth.png` |

**外观**  
蛾灵混生体：人形躯干接巨蛾翅，翅面青绿眼斑与苍白地衣纹；消瘦面庞、复眼般青绿光瞳，头生菌角。腹有淡发光孢子囊，飞行时拖孢子尘。

**习性**  
盘旋于冠层与浮空根桥上方，俯冲抓挠并洒减速/致盲孢子云。可停在垂藤上短暂歇翅。

**战斗提示**  
优先清场，防孢子叠满。俯冲直线可预判；空中受击会短暂坠落后再起飞。有远程手段时优先点杀。

## 古根祭主

| 字段 | 内容 |
|------|------|
| ID | `root_hierophant` |
| 名称 | 古根祭主 |
| 定位 | 区域头目 |
| 立绘 | `Assets/Art/Enemies/forest/enemy_forest_root_hierophant.png` |

**外观**  
树人祭偶：树皮躯干裂开流淌青绿树液脉，冠为纠结古根与苍白地衣鹿角。下半身与巨根融为一体，扣住废墟祭坛残石。胸挂碎石面罩与褪色祭布；枝腕滴翠绿树脂，神情古老而怒。

**习性**  
盘踞森林遗迹最深处的吞树神殿。根须抽打全场，召唤苔缚潜伏者，并从地面拱出尖刺根障；低血量时树液脉狂亮，扩大范围技。

**战斗提示**  
站位避开拱根预警纹；先清小怪再集火本体。枝腕横扫后有硬直。第二阶段孢子/雾更浓，保留位移技能穿根障。击败后可开启通往地下墓穴的根隧（待定）。
