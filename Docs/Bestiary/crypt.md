# 地下墓穴 · 敌人图鉴

大教堂地下的葬厅与骨室：冷炭灰、骨象牙、暗紫灰，伴淡蓝魂烛光。敌人偏「安息被扰、伪圣葬仪」。

立绘目录：`Assets/Art/Enemies/crypt/`

## 棺生遗卒

| 字段 | 内容 |
|------|------|
| ID | `sepulcher_thrall` |
| 名称 | 棺生遗卒 |
| 定位 | 普通近战 |
| 立绘 | `Assets/Art/Enemies/crypt/enemy_crypt_sepulcher_thrall.png` |

**外观**  
半骨朝圣尸：肋骨与颅骨外露，裹尘葬布与残破灰圣装；眼眶燃冷蓝烛光。颈垂碎铁十字架，手持锈蚀仪式短匕。姿态僵直，如刚从棺中撑起。

**习性**  
石棺旁苏醒或成群从侧廊涌出。缓慢逼近，近距连刺；可从半开棺盖「弹出」偷袭。

**战斗提示**  
注意半开棺的预警晃动。单体弱，怕成群；拉开逐个击杀。背后突袭时优先侧滚。

## 铁闸守灵

| 字段 | 内容 |
|------|------|
| ID | `iron_warden` |
| 名称 | 铁闸守灵 |
| 定位 | 精英 / 重型守关 |
| 立绘 | `Assets/Art/Enemies/crypt/enemy_crypt_iron_warden.png` |

**外观**  
高大体甲亡骑：黯铁甲带暗紫锈斑，裂葬面具双眼缝透淡蓝光。胸甲饰铁闸钥匙纹，肩甲挂棺钉与锁链。长柄锈戟形如墓篱尖刺，立于铁门前。

**习性**  
把守墓道铁闸与楼梯口。戳刺、横扫、偶尔掷出锁链钩拽。血量高、移动慢。

**战斗提示**  
戟距长，贴身风险大。等横扫收招进场；钩链有明显前摇，侧移挣脱。可利用台阶高度差绕背。

## 青焰魂灯

| 字段 | 内容 |
|------|------|
| ID | `soul_lamp_wraith` |
| 名称 | 青焰魂灯 |
| 定位 | 飞行 / 远程骚扰 |
| 立绘 | `Assets/Art/Enemies/crypt/enemy_crypt_soul_lamp_wraith.png` |

**外观**  
半透明女魂：苍蓝焰雾躯体，曳长葬纱，面容平静空洞，冷青瞳。下半身化为青魂火；手持或融于锻铁魂灯，灯芯燃淡蓝焰。悬浮于墓室上空。

**习性**  
沿烛台与高拱盘旋，投掷魂火球，贴近时爆发短暂致盲蓝闪。可短暂附身场景魂灯后弹出。

**战斗提示**  
优先清，防远程消耗。火球抛物可预判；附身魂灯时灯火骤亮即预警。近身击破灯体有较长硬直。

## 骨冠司仪

| 字段 | 内容 |
|------|------|
| ID | `ossuary_hierarch` |
| 名称 | 骨冠司仪 |
| 定位 | 区域头目 |
| 立绘 | `Assets/Art/Enemies/crypt/enemy_crypt_ossuary_hierarch.png` |

**外观**  
高耸骨祭司：与石棺岩同化的骨架祭司，叠颅骨冠镶淡蓝魂宝石。灰与暗紫灰破祭服、锈金葬链；巨铁权杖顶悬青焰魂球与倒葬十字。肋骨内透冷青光，立于葬厅台阶。

**习性**  
盘踞墓穴最深处主葬厅。权杖扫击、唤棺生遗卒、以魂球放出十字形青焰阵；低血量时打开侧室铁闸放出铁闸守灵。

**战斗提示**  
地面青焰阵有符文预警，先走位再输出。小怪优先清。第二阶段注意增援。击败后可获通往水淹洞窟的封门钥匙（待定）。
