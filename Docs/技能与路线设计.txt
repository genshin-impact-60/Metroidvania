================================================================================
技能与路线设计
================================================================================

核心人设：主角是被诅咒的朝圣者。通行不只靠体能，还靠「污光」——诅咒之力被圣域排斥，
因此墓穴一类「污秽之地」反而要用 Stained Light 才能踏入。

--------------------------------------------------------------------------------
一、技能一览
--------------------------------------------------------------------------------

【基础】
  移动 / 单段跳 / 近战攻击
  （教堂出生即有）

【冲刺 Dash】
  短距无敌帧突进；过尖刺缝、裂隙门、窄平台空段。
  获取：教堂中段（小Boss / 圣物室，非主Boss）

【墙跳 Wall Jump】
  贴墙连跳，上高井与断壁。
  获取：教堂深处主Boss

【污光 Stained Light】（主题能力）
  诅咒光晕：可穿过「圣洁封印 / 净光障壁」，进入被圣域隔绝的污秽区。
  也可照亮部分幻墙、驱散浅层圣火地刺
  获取：森林主Boss（或森林深处圣物）
  叙事：朝圣者承认并驾驭诅咒，而非被教堂净化。

【下砸 Ground Slam】
  空中下砸破脆弱地板 / 压力板 / 晶壳地面。
  获取：墓穴（主Boss 或 下砸祭坛）

【潜水 Dive】
  水下呼吸与游动；开水下密封门、穿湖底隧道。
  获取：水晶洞窟（区内中段圣物，建议早于洞窟主Boss）

【二段跳 Double Jump】
  空中再跳一次；过断桥、高落差、钟楼入口。
  获取：水晶洞窟深层（潜水之后）——洞窟主Boss 或 水下圣物室

【时间操控 Chrono】（终局能力）
  暂缓齿轮、停摆坠锤、开启黄铜时间门。
  获取：钟楼（中段或钟楼Boss）
  

--------------------------------------------------------------------------------
二、地图连接 ↔ 门控（对照初版剖面图）
--------------------------------------------------------------------------------

连接                        需要的能力           备注
----------------------------------------------------------------------------
教堂 ↔ 森林（石桥）          墙跳                 桥本身可走，森林入口竖井/断墙要墙跳
教堂 ↔ 钟楼（高架桥）        二段跳               桥面断裂；早可见，潜水后才可过
教堂 ↔ 墓穴（中央楼梯）      污光 Stained Light  楼梯被净光障壁封住（叙事向）
森林 ↔ 水晶洞窟（左侧崖道）  潜水                 崖道可下到岸边，湖峡/密封门要潜水
墓穴 ↔ 水晶洞窟（竖井）      下砸                 井底晶壳/脆弱封板，砸穿进入（主入口）
钟楼 ↔ 墓穴（右侧长梯）      时间（主）/ 冲刺(辅) 捷径回程；黄铜门或裂隙
钟楼内部深层                 时间                 终局机关 / 真结局门

原则：每条主连接只「主封」一种能力；第二种能力只让路径更舒服或开可选房。

--------------------------------------------------------------------------------
三、主路线（推荐推进顺序）
--------------------------------------------------------------------------------

① 大教堂（出生 · 枢纽教学）
   - 自由探索上层与部分中层
   - 中段取得【冲刺】→ 打开教堂内裂隙房、为后续全图铺路
   - 深处击败Boss →【墙跳】
   - 此时可见：墓穴净光障壁（缺污光）、钟楼断桥（缺二段跳，长期悬念）

② 蔓生废墟森林（墙跳解锁后）
   - 用墙跳进入森林主区
   - 探索至Boss/圣物 →【污光 Stained Light】
   - 崖道可下探水晶洞窟「岸边」：看见水面与密封门，但不能深潜
   - 可选：森林内用冲刺开少量裂隙宝箱

③ 地下墓穴（污光解锁后）
   - 从教堂中央楼梯，以污光破净光障壁进入
   - 区内取得【下砸】→ 砸穿竖井封板，进入水晶洞窟
   - 本区不再发放二段跳；可用冲刺/墙跳支撑墓穴内部平台

④ 水晶洞窟（下砸进入）
   - 陆地/浅滩可先行
   - 中段取得【潜水】→
       · 开湖底与水下密封门
       · 打通「森林 ↔ 洞窟」崖道回路
   - 潜水后进入深层 → 取得【二段跳】（Boss 或水下圣物）
   - 此时才具备进入钟楼的条件

⑤ 机械钟楼（二段跳解锁后 · 终盘）
   - 主路：回教堂，走高架断桥 + 二段跳进入
   - 内部：冲刺过齿轮缝、二段跳过空段
   - 中段或Boss取得【时间操控】→ 开黄铜门、停摆机关、进入结局区
   - 回程捷径：钟楼 → 墓穴长梯（时间门为主），方便通关后刷图

--------------------------------------------------------------------------------
四、能力获取与「先见后至」对照
--------------------------------------------------------------------------------

能力        获取地              最早用在何处              玩家应早已看见的锁
----------------------------------------------------------------------------
冲刺        教堂中段            教堂裂隙 / 全图尖刺缝     教堂内第一扇裂隙门
墙跳        教堂Boss            森林入口                  教堂通往森林的高墙
污光        森林                教堂→墓穴障壁             中央楼梯净光门
下砸        墓穴                墓穴→洞窟竖井             井底晶壳（可先看到）
潜水        洞窟中段            森林↔洞窟湖峡 / 水下门    森林崖道底的水面门
二段跳      洞窟深层（潜水后）  教堂→钟楼断桥             高架桥缺口（开局即可见）
时间        钟楼                黄铜门 / 终局机关         钟楼内停摆的齿轮门

获取顺序（硬顺序）：
  冲刺 → 墙跳 → 污光 → 下砸 → 潜水 → 二段跳 → 时间

--------------------------------------------------------------------------------
五、设计备注（本版已拍板）
--------------------------------------------------------------------------------

1) 「森林和洞窟之间需要潜水」vs「下砸进洞窟」
   → 洞窟主入口仍是墓穴竖井（下砸）；
     森林崖道是拿到潜水之后的双向捷径。

2) 潜水 → 二段跳 → 钟楼
   → 二段跳发放点必须放在「需要潜水才能到达」的房间，
     保证硬顺序：先潜后双跳，再上钟楼。

3) 墓穴只主发下砸
   → 节奏更干净；墓穴内部用冲刺/墙跳即可，不必再塞二段跳。

4) 钟楼断桥的「长悬念」
   → 开局在教堂就能看见通往钟楼的断桥，但要到洞窟通关后才过得去，
     适合做强期待；注意中段用其他可达景观/NPC提醒玩家「还缺一跳」。

5) 时间能力改为一期必做
   → 钟楼身份就是时间区；拿不到时间就进不了结局，不再用钥匙门凑合。

6) 冲刺来源
   → 仍建议教堂中段精英/侧厅圣物，与主Boss（墙跳）分离。

--------------------------------------------------------------------------------
六、一期最小技能集
--------------------------------------------------------------------------------

  必做：冲刺、墙跳、污光、下砸、潜水、二段跳、时间操控
  可延后：能力进阶（更长潜水、三段跳、时间范围扩大等）

--------------------------------------------------------------------------------
七、一句话主线
--------------------------------------------------------------------------------

从教堂起步，以冲刺与墙跳走出圣域、坠入森林；
在诅咒中点燃污光，走入墓穴，下砸开晶窟；
学会潜水后于湖底夺得二段跳，方才踏上断裂的钟楼桥——
在齿轮与黄铜门前掌控时间，带着污光走完整座废都。
